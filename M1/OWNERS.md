## Shared areas

Nobody owns these as a whole. Each member adds and edits only their own rows or entries.

| Area | Rule |
|---|---|
| Revision History | Add your own row per change; never edit another row |
| Requirements Overview | Edit only rows whose Feature you own; new IDs take the next free number |
| Appendix A: Glossary | Add your own terms tagged with your username; never reword another member's term |
| Appendix C: To Be Determined List | Add your own items tagged with your username; close only your own items |
| `README.md` Team table | Edit only your own row |
